05 / FAQ

What firms ask us first.

Short answers for audit, tax and deal teams.

How soon can we run a real client file?

Most firms run a live engagement within a week. We start from a test in the library and shape it to your method.

Is client data used to train models?

No. Files run your engagements and are deleted when you say so. Access is set per engagement, and each change is recorded with a name and a time.

And if a figure doesn't tie?

Tallyfold marks the row, shows both values side by side and sends it to the reviewer you pick. It never chooses one value on its own.

Can we export the workpapers?

Yes. Schedules, memos and slides export as ordinary spreadsheet, document and slide files, with each source link kept.

Does it work with our practice software?

It links to most ledger and practice tools by API or an open protocol. If yours isn't covered, we build the link with you.
